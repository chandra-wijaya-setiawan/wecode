# Lessons

What an attempt learned, kept where the next one will read it.

## Why

On 14 Sep a fresh worktree could not `pnpm install` at all — pnpm turns an unapproved build
script into an error under `--frozen-lockfile`. Six attempts across three unrelated tasks
failed on it, each one discovering it again from nothing, because the only thing that
crosses an attempt boundary is the branch.

A retry is a fresh agent by design. That is right, and it is exactly why the *lesson* has to
be carried by something other than the agent.

## What a lesson is

| | |
|---|---|
| one sentence | not a report. If it needs a paragraph it is a design document, not a lesson |
| about the world, not the work | *"a fresh worktree needs `pnpm -r build` before the tests import anything"*, never *"I added a null check"* |
| attributable | the assignment that learned it, and when |
| cheap to drop | wrong lessons are worse than none, so dropping one is a single command |

## Where it comes from

The worker writes it, because the worker is the only thing that was there. The brief asks
for it:

> If you learned something a future attempt on this repository should know, end your final
> message with a single line beginning `LESSON:`.

The adapter looks for that line and records it. A harness that cannot be asked simply never
produces one — no adapter is required to.

## Where it goes

| | |
|---|---|
| recorded against the **project**, not the task | the pnpm failure was not about any of the three tasks that hit it |
| rendered into every brief, newest first, **capped** | ten lines. A brief that grows without limit is how the instruction at the top stops being read |
| shown by `wecode lessons` | with its source assignment, so a suspicious one can be traced |
| dropped by `wecode lesson drop <id>` | the operator's call, like everything else that is a judgement |

## What it is not

| | |
|---|---|
| not a memory of the conversation | the session still dies with the attempt. This is one sentence, not a transcript |
| not a rule | a lesson informs the next agent; it does not constrain it. Constraints are scopes and guards, and they are enforced rather than suggested |
| not permanent | it is a note about a world that changes. Ten lines and a `drop` is the whole lifecycle |
