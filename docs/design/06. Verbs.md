# Verbs

Every way the record changes. One definition each — the CLI's commands, the runner's calls
and any future RPC are generated from this list, never written beside it.

Spelling: `wecode <entity> <verb> <id> [options]`.

**Automatic** means no actor invokes it. It fires when its guard becomes true — the cascade
from a passing test up to a delivered epic.

| verb | arguments | from → to |
|---|---|---|

## acceptance_test, task_test

| verb | arguments | from → to | guard |
|---|---|---|---|
| `create` | parent, statement, kind | — → planned | |
| `deliver` | artefact | planned → ready | the artefact resolves |
| `pass` | | ready · failed → passed | |
| `fail` | | ready · failed → failed | |
| `rerun` | | failed → passed · failed → failed | |
| `invalidate` | | passed → ready | |
| `drop` | | planned · ready · failed → dropped | |

`kind` is `script` or `judged`. A `script` test is run by the runner directly; a `judged`
test is performed by a worker, and gets an assignment.

## assignment

Created by the allocator, advanced by the runner. Nothing else invokes these.

| verb | arguments | from → to | guard |
|---|---|---|---|
| `create` | objective, worker, scope, budget, worktree | — → pending | the objective is `ready` and within the attention budget |
| `start` | session id | pending → running | |
| `ask` | kind, question, options | running → waiting | |
| `answer` | text, answered_by | waiting → running | kind `approval` may be answered only by the operator |
| `finish` | | running → succeeded | |
| `fail` | reason | pending · running · waiting → failed | |

## role

| verb | arguments | from → to |
|---|---|---|
| `create` | name, write globs, tools | — → — |
| `edit` | | — → — |

**Only the operator invokes these.** A worker that could widen its own scope has no scope.

## Reads

| verb | shows |
|---|---|
| `board` | what is running, what needs a person, what is queued, what is stuck |
| `show <entity> <id>` | one record and its children |
| `list <entity>` | filtered by state, parent, or role |

Reads change nothing and are open to every client.
