# Role config

Roles are configuration, not code: the person who owns what an agent may touch must be able
to change it without opening TypeScript.

`config/roles.yaml`, in the workspace. Read at the start of every verb that uses it, never
cached across a run.

## The file

```yaml
invariants:                      # apply to every role. No role may override them.
  never_touch:
    - ".github/**"
    - "infra/**"
    - "**/*.pem"
    - "**/*.key"
    - "**/.env"
  never_run:
    - "git push --force*"
    - "npm publish*"
    - "terraform apply*"
    - "rm -rf /*"

defaults:
  budget: { tokens: 250000, seconds: 3600 }
  harness: claude-code

roles:
  engineer:
    worker_kind: agent
    scope:
      write: ["src/**", "tests/**", "config/**"]
      tools: ["bash", "read", "edit", "write"]

  acceptance-tester:
    worker_kind: agent
    scope:
      write: ["tests/acceptance/**"]
      tools: ["bash", "read", "edit", "write"]
    budget: { tokens: 120000, seconds: 1800 }

  analyst:
    worker_kind: agent
    scope:
      write: ["docs/**"]
      tools: ["read", "edit", "write"]

  reviewer:
    worker_kind: human
    scope:
      write: []
      tools: []
```

## Fields

| key | type | |
|---|---|---|
| `invariants.never_touch` | globs | refused for every role, always. Not a default — a ceiling above the ceiling |
| `invariants.never_run` | command patterns | same |
| `defaults.budget` | budget | used by any role that does not set its own |
| `defaults.harness` | string | which coding agent CLI an agent role runs as |
| `roles.<name>.worker_kind` | `agent` · `human` | a human role gets no flags; it gets a message |
| `roles.<name>.scope.write` | globs | the **ceiling**. A task may narrow it and never exceed it |
| `roles.<name>.scope.tools` | tool names | the same, for tools |
| `roles.<name>.budget` | budget | optional; falls back to `defaults` |
| `roles.<name>.harness` | string | optional; falls back to `defaults` |

## Rules

| | |
|---|---|
| **no role grants itself** | the file is not writable by any role. The operator edits it, and `never_touch` includes it |
| **the ceiling is checked twice** | at `task scope`, so an impossible task is refused early; and at `assignment create`, so a scope edited afterwards cannot widen a running attempt |
| **invariants win** | a role listing `infra/**` is a config error, not a permission |
| **unknown keys are an error** | a typo that silently grants nothing is worse than a refusal to start |

## How a role becomes flags

The adapter translates, and only the adapter knows how:

| role field | Claude Code | a human worker |
|---|---|---|
| `scope.write` | the worktree, plus `--add-dir` | named in the message |
| `scope.tools` | `--allowedTools` | — |
| `budget` | watched by the runner, reported by the session | — |
| `harness` | which binary to start | — |

Above the adapter a role is a set of names. Below it, it is whatever that kind of worker
understands.
