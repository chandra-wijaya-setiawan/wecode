# Healing

wecode checking itself, and fixing what it safely can.

**First on release 0.0.2.** Not started; recorded so it is not invented twice.

## Why

The record drifts from the world, and today nobody notices. Seen in one afternoon: a story
`delivered` whose branch never reached the base; a task `done` whose worktree still stood; a
refusal saying *no worker free* for forty-two passes with ten workers idle; a branch with no
story left; two assignments `running` under a runner that no longer existed.

None of those is a bug in one place. They are the record and the world disagreeing, which
is a thing a system should be able to notice about itself.

## The two halves

| | |
|---|---|
| **the check** | one pass of invariants. It reads and reports, and changes nothing |
| **the healing** | what follows, and only some of it is automatic |

## What is checked

| invariant | the drift it catches |
|---|---|
| a `delivered` story has a `landed_sha` | delivered but never merged |
| a `done` task has every task_test `passed` | a verdict that no longer follows from its evidence |
| an open assignment has a live session | a runner died under it |
| every worktree belongs to an open assignment or an unlanded story | leftovers |
| every `story/` and `task/` branch has a row | branches for work that was dropped |
| a refusal is newer than its task's `updated_at` | a stale reason on the board |
| a project's lessons are within the brief's cap | a brief nobody will read to the end |
| an `in_progress` story has work under it | a shape with nothing in it |

Each is a sentence a person could check by hand. That is the bar: **if it cannot be
explained in one line, it is not an invariant, it is an opinion.**

## What it may fix by itself

Only what is reversible and loses nothing.

| safe | |
|---|---|
| clear a stale refusal | it was already wrong |
| release a worktree with no uncommitted files | the branch is the copy |
| mark an assignment whose runner is gone as `lost` | it is what happened |
| re-run a check that never ran | evidence, not judgement |

## What needs approval

Anything that loses work, rewrites history, or changes a verdict.

| major | why it is asked |
|---|---|
| delete a branch holding commits that are nowhere else | the only copy |
| drop a row somebody created | it was a decision |
| reopen a delivered story | it changes what was said to be true |
| force a ref | history |

A major fix is **proposed, never applied**. Healing creates a `heal` chore — a system task,
performed by a system worker — and because that kind is declared as needing approval, the
chore is created but **not dispatchable**: it waits on `needs_human` of kind `approval`, and
the operator is **notified** through the subscription sinks of
[15](15.%20Subscriptions.md).

Approval comes **before** the system worker is started, not after. A fix that might lose
something is not done and then reviewed.

| | |
|---|---|
| what is proposed | one chore per drift, naming the invariant, what it found, and exactly what it would do |
| who performs it | a system worker, under the `system` role, once approved |
| what proves it | the invariant that was broken now holds |
| what happens if refused | the chore is dropped and the drift stays on the board, said out loud rather than hidden |

**That notification is not a relay.** A relay carries somebody's words to somebody else.
This is wecode speaking for itself, about itself, to the one person who can answer — which
is the one case where wecode is the author of the message.

## What it must never do

| | |
|---|---|
| **invent work** | healing repairs the record; it does not decide what should be built |
| **change a verdict** | a test's result is evidence. Healing may re-run a test; it may never mark one passed |
| **be omnipotent** | a check it cannot explain in one line does not belong. An unexplained fix is worse than visible drift |
| **run without a record** | every heal, safe or major, is a ledger line with what it found and what it did |

## Shape

```
wecode check            one pass, reads only, prints what drifted
wecode check --heal     applies the safe fixes, proposes the major ones
```

The runner runs the same pass on a slow tick — once a minute is plenty for a thing that
looks for things nobody noticed.
