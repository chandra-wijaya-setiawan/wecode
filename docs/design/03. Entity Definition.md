# Entities

| entity | short description |
|---|---|
| **workspace** | where wecode keeps your projects together in one place |
| **project** | a software project: one codebase, an objective, and the work to get there |
| **release** | a version of the project, delivered as one thing |
| **epic** | a large body of work within a release, too big to deliver in one go |
| **story** | one capability a user can name, small enough to deliver whole |
| **requirement** | what must be true |
| **acceptance_criteria** | one named expectation that proves a requirement is met |
| **acceptance_test** | the artefact that proves an acceptance_criteria |
| **task** | one piece of work, small enough for one worker to finish |
| **task_test** | the artefact that proves a task did its own part — what is usually called a unit test |
| **assignment** | one worker's promise to complete one objective — a task or a test — held open until it is met, abandoned, or the worker fails |
| **role** | the kind of work a worker does: which files it may change, and which tools it may run |
| **worker** | a human or an agent that performs an assignment |
