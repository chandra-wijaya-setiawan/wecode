# C4 — the north star map

Levels 1 and 2, per Simon Brown's C4. L3 (components) is the crate table below —
the `components` task formalizes it; L4 is the code and is never drawn by hand.
Every box here exists today; planned boxes are marked ⏳.

## L1 · System context

```mermaid
graph TB
    OP["Operator (Chandra)<br/>chief of staff"]
    TG["Telegram<br/>approvals + digests away from keyboard"]
    WC["<b>wecode</b><br/>control plane for autonomous<br/>software-development projects"]
    HA["Coding harnesses<br/>claude-code · codex · opencode ⏳<br/>(the seats; A2A envelope in, diff out)"]
    GR["Git repositories<br/>~/projects/* · GitHub · GitLab"]

    SB["Sandbox providers ⏳<br/>local · docker · e2b"]

    OP -->|defines projects, signs gates| WC
    WC -->|notify.sh: digests, buttons| TG
    TG -->|signed replies| WC
    WC -->|task envelope, budgets, scopes| HA
    HA -->|commits into worktrees| GR
    WC -->|branch, verify, merge, report| GR
    WC -->|issue links, MR flow| CI
    WC -->|injects, expires| CL
    WC -.->|SandboxProvider trait| SB
```

The boundary sentence (maturity-roadmap.md): wecode consumes harnesses, sandboxes,
forges and clouds; it becomes none of them.

## L2 · Containers

```mermaid
graph TB
    subgraph wecode system
        CLI["wecode CLI<br/>(one binary; the only thing that executes)"]
        LOOP["wecode loop<br/>(same binary, resident: tick → dispatch → telegram)"]
        TUI["cockpit: tui / board<br/>(same binary, read-mostly)"]
        DB[("wecode.db · SQLite<br/>plan, ledger, runs, audit —<br/>the database IS the event bus")]
        WS["company workspace<br/>company.toml · playbooks · gaps<br/>(hand-edited; never reachable from a post's cwd)"]
        WT["run worktrees<br/>~/.wecode/run/&lt;org&gt;/&lt;task&gt;<br/>(disposable; one per task)"]
        AG["agent seat process<br/>(ephemeral; spawned per run,<br/>budgeted, scope-guarded)"]
    end

    CLI --> DB
    LOOP --> DB
    TUI --> DB
    CLI -->|reads| WS
    CLI -->|git worktree add / repair / remove| WT
    LOOP -->|spawn, supervise, kill on budget| AG
    AG -->|writes only declared scopes| WT
    AG -->|result.json| WT
```

| Container | Runs as | Owns | Talks to |
|---|---|---|---|
| wecode CLI | invoked per command | admission, verify, merge, rollback | db, workspace, git |
| wecode loop | resident process | dispatch cadence, telegram channel | db, agent processes |
| cockpit (tui/board) | invoked | rendering only | db |
| wecode.db | SQLite file | all state; every event | everyone (the bus) |
| company workspace | directory | roles, posts, invariants, playbooks | read by CLI only |
| run worktree | git worktree | one task's working copy | agent, verify |
| agent seat | ephemeral child | nothing durable | its worktree only |

## L3 · Components (the crates, ordered by dependency)

| Crate | Hides (Parnas) |
|---|---|
| core | pure types; admission's defect calculus — no I/O, no serde |
| gov | the Broker: authorization as a pure function of its inputs |
| org | parsing the hand-edited workspace |
| store | SQLite; how events persist |
| cli | that anything executes at all |

One rule keeps L2 honest: **no arrow into wecode.db except through store, and no
process but the CLI binary family ever holds it open.**
