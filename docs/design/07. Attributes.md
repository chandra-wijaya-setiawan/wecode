# Attributes

What each entity holds. Types are TypeScript; states and enums are the ones in
[05](05.%20Entity%20State%20Diagram.md).

## On every entity

| field | type | |
|---|---|---|
| `id` | `number` | the short number you type — `#485` |
| `slug` | `string` | a readable handle, unique under its parent |
| `state` | union | its own state set |
| `created_at` | `timestamp` | |
| `updated_at` | `timestamp` | |

Only `assignment` departs from this: its `state` is `status.phase`, and it has a `spec` that
is never rewritten.

## Shared shapes

| shape | fields |
|---|---|
| **scope** | `write: string[]` — globs it may change · `tools: string[]` — commands it may run |
| **budget** | `tokens: number` · `seconds: number` |

## Two rules the shapes carry

| | |
|---|---|
| **an assignment copies its scope** | so editing a task's scope cannot widen an attempt already running |
| **a role's scope is a ceiling** | a task may narrow it and never exceed it. The check belongs to `task scope` |
