# Health

What sick means, where it is written down, and who is allowed to say it is better.

**On release 0.0.3.** The checking half exists; nothing here is built. Extends
[19. Healing](19.%20Healing.md), which named the checks and the two halves.

## Terms

| term | definition |
|---|---|
| **healthy** | the record agrees with itself and with the world |
| **sick** | a row whose state is contradicted by evidence — its children, its verdicts, or the tree |
| **drift** | the disagreement itself, always a pair: what the record says, what is true |
| **failing** | a truthful red verdict. **Not sick** — the machine is working |
| **blocked** | waiting on a person or an unmet precondition. Not sick |
| **stalled** | not blocked, not running, not finished, and nothing will move it. Sick |
| **violation** | one row: a named invariant does not hold, with the pair that proves it |
| **healing** | restoring agreement. Safe if reversible and nothing is lost; otherwise proposed |
| **collection** | removing what nothing needs. Never restores anything |

Two sentences behind all of it: **failing is health, silence is sickness**, and **a symptom is
never healed, only its cause** — no check is satisfied by editing a verdict.

## Stalled

Three conditions, all required.

| |
|---|
| its state says it is going somewhere — `ready`, `in_progress`, `running`, an open chore |
| nothing will move it: no assignment, no worker, no next pass that changes anything |
| nobody has been told: it is not failed, not waiting on a person, not on any panel |

Observed 16–17 Sep: tasks 283, 287 and 288 sat `ready` with no assignment for seven hours,
three hours and twice more, because the task branch carried commits the story branch lacked
and the refusal was logged once and then repeated to nobody. An empty queue with a quiet log
is idle; a **ready task** with a quiet log is a stall, and the two must never look alike.

## Sick, per level

| entity | sick when |
|---|---|
| project | it has releases but no open work while stories remain undelivered |
| release | `in_progress` with no epic, or every epic delivered while it is not |
| epic | `in_progress` with no story, or all stories dropped while it claims success |
| story | `delivered` but its branch is not an ancestor of the base; `in_progress` with no requirement; open with a failing criteria and no task |
| requirement | no criteria, or every criteria dropped while it stands |
| acceptance_criteria | failing with no open task; passing while its test never ran at this base |
| acceptance_test | `ready` with no red-at-base proof; `passed` against a tree nobody has now |
| task | `done` while a task_test is not `passed`; `ready` with no ready task_test; `ready` for a role with no worker; **`ready` and undispatchable for N passes** |
| task_test | `passed` at a provenance older than the base; never run while its task is `done` |
| assignment | open with no live session; `succeeded` with no commit for a kind that must commit; `waiting` with no question |
| chore | open after its condition has gone; `done` without proof |
| worker | idle while its role has ready work |
| branch · worktree | a branch with no row; a worktree belonging to no assignment and no unlanded story |

## Two axes, because they heal differently

| | record vs record | record vs world |
|---|---|---|
| example | `done` task with a failing task_test | `delivered` story whose branch never merged |
| detected by | reading the database alone | asking git, the filesystem, the process table |
| healed by | **never automatically** — a contradiction is a judgement somebody made | usually safely: the world is the fact |

## The violation

| column | holds |
|---|---|
| `subject_type`, `subject_id` | any level, project to task_test — and `branch`, `worktree` |
| `invariant` | the check's name, e.g. `stalled_no_dispatch` |
| `kind` | `stalled · contradicted · orphaned · unproven · drifted` |
| `finding` | one sentence: what the record says, what is true |
| `evidence` | the sha, the path, the count of passes |
| `first_seen`, `last_seen` | written every pass the condition holds — duration is derived from these |
| `cleared_at` | set by a pass that no longer finds it |
| `heal` | `none · safe · needs_approval`, declared by the check |
| `refused_at`, `refused_reason` | your decision to live with it |

**Only findings are stored. No row means healthy.** A row per subject per check would be
thousands of rows for a healthy repository, and a stale `healthy` left by a check that
crashed is the worst state of all.

**Duration is why anything is stored at all.** Stalled is a claim about time; a snapshot
cannot see it. Everything else stays derived: `is_sick(subject)` is a query, never a column.

## The pass

| column | holds |
|---|---|
| `at`, `duration_ms` | when it looked, and for how long |
| `checks_run`, `checks_failed` | what it managed to ask |
| `build` | the provenance of the doctor that ran |

**Healthy and never-looked must not look alike.** An empty violations table proves nothing
without a recent pass beside it.

## Who writes, who clears

| actor | may create | may clear | does instead |
|---|---|---|---|
| the doctor pass | **the only writer** | yes — by not finding it | holds the runner's lease |
| `wecode doctor` at the terminal | no | no | runs the same checks and prints |
| main, allocator, foreman, examiner | no | no | *cause* clearing by doing their work |
| a system worker performing a heal | no | no | changes the world; the next pass clears the row |
| an agent in a task | no | no | cannot see the table |
| a person | no | no | answers an approval, or records a refusal on an open violation |

| rule | why |
|---|---|
| a violation is not clearable by whoever caused it | else the four-times-in-one-night pattern — the real diagnosis — never appears |
| clearing is not a verb anybody can call | `cleared_at` is set by re-derivation, so it cannot be faked |
| a violation must survive two consecutive passes before it counts | a pass that reads a half-finished tick must not accuse it |
| a refusal suppresses re-proposal and keeps the row open | a drift you chose to live with is stated, not hidden |

## Healing is work, gated like work

| stage | who |
|---|---|
| diagnose | `runner:doctor` — writes the violation, never acts |
| turn it into work | `runner:healer` — reads open violations, creates nothing else |
| allocate | `allocator:diagnosis` for a safe heal; `allocator:approval` for a major one |
| perform | a system worker, through the foreman, under the `system` role |
| prove | the next doctor pass no longer finds the violation |

**Approval comes before the worker starts.** A fix that might lose something is never done
and then reviewed. The three closures of a violation are **healed**, **resolved elsewhere**
(the world moved; indistinguishable, and that is fine) and **refused** — which keeps it open.

## Safe, and not

| safe to heal | |
|---|---|
| clear a stale refusal | it was already wrong |
| release a worktree with nothing uncommitted | the branch is the copy |
| mark an assignment whose runner is gone as lost | it is what happened |
| re-run a check that never ran | evidence, not judgement |
| tag a diverged task branch and re-cut it | the commit is kept under `attempt/<slug>@<n>` |

| needs your signature | |
|---|---|
| delete a branch holding commits nowhere else | the only copy |
| drop a row somebody created | it was a decision |
| reopen a delivered story | it changes what was said to be true |
| force a ref | history |

## Invariants

| |
|---|
| the doctor pass is the only writer of violations, and has no path to the engine or the trees |
| no row means healthy; a pass row says when it last looked |
| a violation clears only by re-derivation, never by a verb |
| every check is one sentence a person could verify by hand |
| a major heal is proposed and waits on an approval assignment; it is never applied first |
| a refused violation stays open, with the reason |

## What this is not

| |
|---|
| **not a flag on every entity.** `is_sick` is a query; a stored derivation is the thing this codebase already refuses |
| **not a diagnosis.** A check knows a rule is broken, not why — the repetition is the diagnosis |
| **not an audit trail of work.** Verdicts, attempts and lessons already have homes |
| **not self-repair of judgements.** A contradiction between a state and its evidence is always a person's call |

## Leans on

Kubernetes — conditions owned by the controller, recomputed every reconcile, never set by the
author of the object; level-triggered reconciliation, so nothing needs a flag cleared. Murphy,
Notkin & Sullivan, *Software Reflexion Models* — declared model, actual source, and the
convergence, divergence and absence between them, which is the record-vs-world pair. Design
19 for the checks themselves and the safe/major split.
